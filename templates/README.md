# 記事の書き方

このフォルダはテンプレートを置くためだけのフォルダで、サイトには公開されません
（`_config.yml` の `exclude` で除外しています）。

## ブログ記事を追加する

1. `templates/blog-post-template.md` をコピーして `_blog/` フォルダの中に置く
   （ファイル名は半角英数字とハイフンのみ。例: `core2026-report.md`）
2. ファイル冒頭の `---` に囲まれた部分（フロントマター）を書き換える
   - `title`: 記事タイトル
   - `date`: 公開日（`YYYY-MM-DD` 形式）
   - `description`: 記事の説明文（1〜2文）
   - `category`: 「活動報告」「大会レポート」「技術記事」など
3. 2つ目の `---` より下に本文をMarkdown記法で書く
4. 保存すると `/blog/ファイル名/` というURLでページが公開され、
   `/blog/` の一覧やトップページの「■ブログ記事」欄にも自動的に追加されます

## お知らせ（news）を追加する

1. `templates/news-post-template.md` をコピーして `_news/` フォルダの中に置く
   （ファイル名は半角英数字とハイフンのみ。例: `taikai-shutsujo.md`）
2. フロントマターの `title` `date` `description` を書き換える
3. 2つ目の `---` より下に本文をMarkdown記法で書く
4. 保存すると `/news/ファイル名/` というURLでページが公開され、
   `/news/` の一覧やトップページの「■お知らせ」欄にも自動的に追加されます
