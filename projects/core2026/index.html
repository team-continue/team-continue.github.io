■プロジェクト概要
CoRE 2025の経験をもとに、自律移動と自動照準を大幅に強化した2代目機体のプロジェクトです。ROS 2ベースのソフトウェアスタックを整備し、上位入賞を目指しています。

■競技課題の概要
CoRE 2026では、自動機と操縦機が混在するフィールドで、自律性の高さが勝敗を分けます。自己位置推定・経路計画・自動照準を組み合わせた戦略が求められます。

■ロボットの特徴
2D LiDARによる自己位置推定、コストマップベースの経路計画、画像処理による自動照準、モジュール化された発射機構が特徴です。
