CoRE 2026　ソフトウェア
[トップ]　[メカ]　[回路・電装]　[ソフトウェア]

■ソフトウェア全体構成
ROS 2をベースに、自己位置推定→経路計画→経路追従→車体制御のパイプラインを構成しています。 センサにはLiDARを使用し、各機能を独立したノードとして実装しています。

■開発環境
使用OSUbuntu 24.04
フレームワークROS 2 Jazzy
言語C++ / Python
シミュレータGazebo（機体モデルで走行・射撃を再現）

■ノード構成
ノード役割
local_costmap_builderLiDAR点群から局所コストマップを生成
path_plannerコストマップ上で目標地点までの経路を計画
path_follower計画された経路への追従速度指令を生成
body_controller速度指令をメカナム4輪の回転数へ変換しマイコンへ送信
shooterターゲット認識結果に基づく砲塔制御と発射管理

■トピック構成
/scan（LiDAR）→ local_costmap_builder → /local_costmap → path_planner → /path → path_follower → /cmd_vel → body_controller という流れでデータが受け渡されます。

■TF構成
map → odom → base_link → lidar_link / turret_link のツリー構成です。

■自己位置推定
LiDARスキャンマッチングとホイールオドメトリを融合して自己位置を推定しています。

■経路計画
path_plannerでコストマップ上のA*探索により経路を生成し、障害物出現時は再計画します。

■制御
path_followerがPure Pursuit方式で追従し、body_controllerが各輪へ分配します。

■UI / GUI
オペレータ用のUI / GUIとして、コストマップ・経路・残弾数をブラウザで確認できる管制画面を製作しました。
