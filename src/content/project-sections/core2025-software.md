## ソフトウェア全体構成

CoRE 2025 のソフトウェアは、STM32 上のファームウェア単体で完結するシンプルな構成です。コントローラ入力を受け取り、メカナムホイールの逆運動学計算とモータ制御を行います。

## 開発環境

- 言語: C++
- ビルド: PlatformIO
- バージョン管理: GitHub

## 制御

- コントローラ入力 → メカナム逆運動学 → 各輪速度指令
- ホイールエンコーダによる PID 速度制御
- フライホイールの回転数管理と発射シーケンス制御

## UI / GUI

大会用の GUI は用意せず、デバッグはシリアルモニタで実施しました。この経験が CoRE 2026 での UI 開発の動機になっています。
